# SFS-Blueprints
Hand-crafted blueprints library for Spaceflight Simulator.
All JSON files are manually written, no extracted game assets.

## Compatibility
Works on SFS 1.5 and above, both official release and store-modified builds.

## Manual Installation Guide
### SFS 1.5 or older
Path:
`/storage/emulated/0/Android/data/com.StefMorojna.SpaceflightSimulator/files/Saving/Blueprints/`

### SFS 1.6 and newer (storage migrated to media)
Path:
`/storage/emulated/0/Android/media/com.StefMorojna.SpaceflightSimulator/files/Saving/Blueprints/`

Steps:
1. Create a new folder inside the `Blueprints` directory (name it after your rocket).
2. Put `blueprint.txt` and `version.txt` into this new folder.
3. Fully close and restart Spaceflight Simulator. The blueprint will load automatically.

## Important Warnings
1. Modified / pirated SFS builds have tweaked physics. Rockets may behave strangely or explode during launch. Not responsible for any launch failure.
2. Save text files with UTF-8 encoding. Wrong encoding will cause SFS to fail loading the blueprint.
3. These blueprints are for personal gameplay only. Commercial use is prohibited.
4. CDN link is a backup download option. The QQ group is the main community channel.
5. If you cannot locate the folder, check both paths above. Some modified builds use the old data path even with version marked 1.6.
